# Neon Flux wallpaper

`neon-flux-desktop-3840x2160.png` is generated by the existing
`parts/wallpaper/make-wallpaper.py` in Miko's `~/Documents/neon-flux` checkout,
using that repository's canonical `palette.json`, the default 3840 × 2160
resolution, and 2× supersampling. It is generated artwork, not a downloaded image.

To regenerate, run that generator in a Python environment containing NumPy and
Pillow, then copy the full-size desktop PNG from its `build/` directory here.
Do not copy the reduced `-preview.png`. The source checkout is only needed for
regeneration; Nix builds and other machines use the image shipped here.

## Safe previews

### Plasma lock screen

Validate the render with `kscreenlocker_greet --testing` and isolated XDG config
paths on a separate virtual X server; never invoke a real lock to take a preview
screenshot.

### SDDM login screen

Build the theme package and test with `sddm-greeter-qt6 --test-mode --theme
<package>/share/sddm/themes/neon-flux`. Set `QT_FORCE_STDERR_LOGGING=1` to see
loader diagnostics; the socket error in test mode is expected because no SDDM
server is connected. Test mode does not prove real authentication: that needs a
manual login after deployment. Never restart the display manager during an
active session just to preview the theme.
